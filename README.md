# THE HUNT

A third-person horror roguelike vertical slice built in **Unreal Engine 5**, combining Soulslike combat with a procedural roguelike board inspired by *Slay the Spire*.

![The Hunt](docs/images/image21.png)

## Report

The complete project report is available as a GitHub-friendly, clickable Markdown document:

**[Read the full report →](docs/report.md)**

The report includes the development process, learning goals, architecture, AI, combat, inventory, procedural map generation, progression, QA, reflection, asset credits, references, and appendix.
